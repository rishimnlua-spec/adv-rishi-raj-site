# Advocate Rishi Raj Singh - Professional Website

A modern, responsive website for Advocate Rishi Raj Singh, a trusted legal professional at the High Court of Patna.

## 📋 Overview

This website showcases the professional services of Advocate Rishi Raj Singh, featuring information about his practice, expertise, and legal services. The site is built with HTML, CSS, and JavaScript with a focus on responsive design and user experience.

## 🎯 Features

### Pages
- **Homepage** (`index.html`) - Hero section, about, services, blogs, and contact information
- **About Page** (`about.html`) - Detailed biography, achievements, and statistics
- **Contact Page** (`contact.html`) - Contact form and communication channels
- **Blog Page** (`blog1.html`) - Legal articles and insights

### Key Sections
- **Hero Section** - Professional header with background image and call-to-action
- **About Section** - Profile information with professional photo and credentials
- **Services Grid** - 15+ practice areas including:
  - Writ Matters
  - Civil & Criminal Cases
  - Election Cases
  - NDPS Cases
  - Property Disputes
  - Consumer Forum Cases
  - And many more
- **Blog Hub** - Legal analysis and articles
- **Contact Section** - Multiple contact methods and form
- **Responsive Navigation** - Mobile-friendly menu with hamburger toggle

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- Python 3+ (for running local server)

### Running the Website

#### Using Python HTTP Server
```bash
# Navigate to the project directory
cd /path/to/personal\ project

# Start the server on port 8000
python3 -m http.server 8000

# Open in browser
# http://localhost:8000
```

#### Using other servers
- Live Server (VS Code Extension)
- Node.js http-server
- Any other local development server
